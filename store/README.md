# Store assets

- `icon-512.png` — Google Play icon (512×512).
- `icon-1024.png` — App Store icon (1024×1024, opaque).
- `feature-graphic.png` — Google Play feature graphic (1024×500).
- `listing-ru.md` — draft title/short/full descriptions and keywords.
- `screenshots/` — put final device screenshots here; no QA/debug screens.

Regenerate the icon/feature graphic after a branding change. Screenshots must be
captured from the store build on real devices and must not show test identities,
internal diagnostics or other people's data.
