# Задания для первого испытания

Сервер и браузерный участник: **https://p2p.lienad.ru**.
Android APK: **https://p2p.lienad.ru/download/messenger-preview.apk**.

Эта сборка проверяет связь 1:1. Боты, каналы и бэкапы не нужны.
Нативный Android APK имеет встроенный JavaScript и не требует Expo Go или Metro.
Это внутренняя тестовая сборка с тестовой подписью, не выпуск для Google Play.
Она предназначена для современных 64-битных Android-устройств (arm64), Android 7+.

## 1. Соединить два устройства

- Установить APK на два Android-телефона. Вторым участником может быть Chrome
  на компьютере с браузерным диагностическим клиентом.
- Оставить адрес сервера `https://p2p.lienad.ru`. Ваш компьютер для работы APK
  не требуется. Браузерного участника можно открыть по этому же адресу.
- Сначала проверить в одной Wi-Fi сети, затем по возможности Wi-Fi↔мобильная сеть.
- «Только через TURN» пока не включать: резервный маршрут ещё проверяется отдельно.
- Создать приглашение на одном устройстве, скопировать его на другое, подключиться.
  Приглашение секретное; не присылать его вместе с отчётом.

Для локального запасного варианта на Mac есть `start-local-test.command`.
Внутренний APK явно разрешает HTTP к частным LAN-адресам; внешние адреса требуют
HTTPS. Установка APK выполняется вручную; системное разрешение установки из
выбранного источника понадобится.

## 2. Проверить разговор и вложение

- Отправить несколько сообщений в обе стороны.
- Отправить документ или фото 1–5 МиБ и открыть полученный файл.
- Сделать аудиозвонок на две минуты; затем поменяться ролями звонящего.
- Проверить выключение микрофона, завершение звонка и повторный звонок.
- Сделать короткий видеозвонок и проверить картинку/звук в обе стороны.

Оба приложения держать открытыми. Сворачивание пока закрывает соединение.
Офлайн-доставка, голосовые заметки и сохранение истории будут в следующих сборках.

## 3. Прислать результат

Достаточно одного сообщения:

```text
Телефон 1: модель, версия Android
Телефон 2: модель, версия Android (или Chrome/ОС)
Сеть и операторы: одна Wi-Fi сеть / Wi-Fi↔LTE / другое
Текст: работает / ошибка
Файл: размер, открылся ли
Аудио: слышно ли обоих, эхо, обрывы
Видео: картинка и звук в обе стороны
Повторный звонок: работает / ошибка
Диагностика: напрямую/через TURN, RTT и потери (если показаны)
Ошибка: текст и действие, после которого появилась
```

При проблемах между разными операторами укажите операторов и тип сети: некоторые
NAT и фильтры потребуют пока не подтверждённый TURN-маршрут. Устойчивость к DPI
ещё не подтверждена. Приглашение и другие секреты в отчёт не включать.

## Для iOS

Android APK на iPhone не устанавливается. Следующая задача — собрать и подписать
iOS-приложение с полным Xcode, затем выбрать установку на зарегистрированное
устройство или TestFlight. Для TestFlight нужен аккаунт Apple Developer.
JavaScript обеих платформ уже экспортируется, но это не подписанный IPA.
Достаточно сообщить, есть ли Apple Developer и какая модель iPhone будет
использоваться. Пароли присылать не нужно.
