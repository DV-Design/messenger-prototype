# LastCall 0.5.0 — короткие задания

APK: https://lienad.ru/messenger/download/LastCall-0.5.0.apk
Сервер: https://lienad.ru/messenger
Логика доставки и варианты: https://lienad.ru/messenger/architecture.txt

Установите поверх прошлой сборки на двух Android-телефонах. Не удаляйте старое
приложение: его ключ и история хранятся локально. Android 7+, arm64, тестовая
подпись. Expo Go и работающий компьютер не нужны.

## Сначала — проверка мобильного интернета

Публичный резервный TURN уже включён и проверен извне по UDP/TCP/TLS.
Новый APK не нужен, если у обоих уже 0.5.0: полностью закройте и снова откройте
LastCall на обоих телефонах, чтобы обновить настройки соединения.

1. Оставьте оба приложения открытыми. Отключите Wi-Fi на обоих телефонах;
   по возможности используйте разных мобильных операторов.
2. Обменяйтесь текстом, небольшим файлом и аудиозвонком. Проверьте две галочки,
   содержимое файла и звук в обе стороны. В диагностике маршрут может быть
   «P2P напрямую» или «через TURN» — резервный маршрут допустим.
3. Во время звонка переключите Wi-Fi → мобильный интернет → Wi-Fi. Запишите
   длительность тишины и сохранился ли звонок. Бюджет восстановления — 10 секунд,
   это не гарантия непрерывного звука или работы в любой сети.
4. При сбое пришлите операторов, модели телефонов и отчёт из «Настройки →
   Диагностика → Скопировать отчёт о соединении»; ключи и переписка не нужны.

FCM на сервере пока выключен: эту проверку выполняем при обоих открытых
приложениях. Наличие TURN не включает уведомления в закрытом приложении.

## Регистрация и каталог

1. После обновления прежние логин, контакты и история должны сохраниться. На уже
   зарегистрированном устройстве новой анкеты быть не должно.
2. На новой установке системные запросы микрофона, камеры, фото и уведомлений
   должны появиться автоматически перед регистрацией. Их запрашивает ОС по одному;
   отказ от одного не должен блокировать следующие. Телефонная книга не нужна.
   Ранее выданные разрешения ОС повторно не запрашивает.
3. Если устройство ещё не зарегистрировано, укажите имя и уникальный логин. Имя
   может повторяться; логин — 3–24 латинские буквы, цифры и _. Подтверждение идёт
   от сервера. Номер телефона и SMS не используются.
4. Если есть другая новая установка, попробуйте занятый логин: сервер должен
   отказать. После успешной регистрации другой логин тем же ключом не регистрируется.
5. В «Контактах» откройте каталог сервера, обновите его, найдите собеседника по
   @логину и по имени. Проверьте русское имя в другом регистре. Офлайн-профили тоже
   доступны. Участники каталога не добавляются в чаты автоматически.

Ограничение «один логин» относится к защищённому ключу установки, а не к аппаратной
идентификации телефона. После удаления/сброса Android ключ может быть утрачен;
восстановить его по одному публичному логину нельзя.

## Переписка, файл и звонок

1. Оба участника открывают чат друг с другом. Обменяйтесь несколькими сообщениями:
   две галочки должны появляться только после реального получения.
2. Сверните получателя, отправьте текст, затем снова откройте его, пока отправитель
   остаётся в сети. Проверьте получение очереди. **Настоящие push пока не настроены**:
   системное разрешение уведомлений не включает Firebase само по себе.
3. Выключите телефон получателя. Отправьте текст и файл до 5 МиБ: они должны
   остаться в очереди. Перезапустите отправителя, затем включите получателя:
   очередь и файл должны восстановиться и доставиться. Подтверждение учитывается
   после сохранения у получателя. При разрыве файл передаётся заново с тем же ID;
   продолжения с последнего байта пока нет. Ожидание — до 7 дней. После срока —
   «Не доставлено за 7 дней», а не галочки. Лимиты preview: 100 ожидающих текстов,
   16 сохранённых файлов / 40 МиБ суммарно. При заполнении новая отправка должна
   вернуть ошибку, сохранив уже ожидающие данные.
4. Начните звонок недоступному собеседнику и сразу завершите его. После открытия
   получателя звонок не должен стартовать сам. Без подключения ожидание заканчивается
   примерно через 30 секунд. Затем при обоих открытых приложениях проверьте обычный
   аудиозвонок, завершение и обратный звонок.
5. Во время звонка переключите Wi-Fi → мобильный интернет, затем обратно.
   Приложение пытается сохранить сеанс и восстановить маршрут в течение 10 секунд.
   Запишите длительность тишины, сохранился ли звонок и ушла ли очередь после
   восстановления. Это бюджет восстановления, не гарантия отсутствия паузы связи.
   Аутентифицированный TURN служит резервом при недоступном прямом маршруте;
   его внешняя проверка не гарантирует проходимость всех операторских сетей.
6. Создайте группу из трёх обновлённых телефонов A/B/C. Отключите C, отправьте
   от A текст и файл, убедитесь, что B их получил. Отключите A, перезапустите B,
   верните C: B должен синхронизировать с C сохранённые данные с авторством A.
   Дубликатов быть не должно. При возвращении A подтверждения должны обновиться
   отдельно для каждого участника. Для этой проверки все участники используют 0.5.

Сначала выполняется прямая попытка. Через 2,5 секунды без ACK отправляется только
тип ожидания, случайный ID и срок действия. Каталог и push не получают текст,
файлы или медиа. При резервном маршруте TURN пересылает зашифрованный трафик
без архива переписки, с расходом серверной полосы.
При выключенном телефоне или отсутствии сети мгновенная доставка невозможна.
Для личного чата отправитель должен снова стать доступен до истечения срока.
В группе данные может дослать участник с сохранённой проверенной копией.
Если все держатели данных недоступны, доставить их некому; серверной почты нет.

FCM/APNs и системные фоновые входящие вызовы требуют отдельной настройки и
испытаний. Эта сборка проверяет управляющую логику, а не доказывает реальную
доставку push. Не используйте текущие результаты как доказательство обхода DPI
или гарантированной связи во всех российских сетях.

## Что прислать

```text
Модели телефонов / Android / операторы:
Сохранился ли профиль после обновления:
Запросы разрешений на новой установке:
Каталог / поиск по логину и имени:
Сообщения при обоих открытых приложениях / после возвращения:
Файл после перезапуска / группа при выключенном авторе:
Оператор и результат без Wi-Fi / пауза при переключении сети:
Обычный звонок / отмена ожидающего звонка:
Текст ошибки и действие перед ней:
```

При сбое: Настройки → Диагностика → «Скопировать отчёт о соединении». Не присылайте
ключи устройства или личную переписку. Криптография ещё не прошла независимый
аудит и не использует ratchet. iOS: подписанного IPA/TestFlight пока нет.
