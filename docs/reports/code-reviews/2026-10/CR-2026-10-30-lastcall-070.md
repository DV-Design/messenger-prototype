# Review: LastCall0.7 background calls, read receipts and video

Date:2026-10-30. Scope: current mobile/core/native changes over a654ba5 plus local progress tooling. Verdict: PASS for release implementation and stated automated/native scope; physical acceptance remains tracked.

## Main review

Reviewed recent mobile/core transport history and the actual modified code. The managed-account gate,9s universal wake window, missing post-invite wake on an apparently connected RTC session, local-only markRead and permanent300k/high-RTT video cap explain the reproduced/source-traced failures.

The implementation keeps receipt signatures domain-separated, binds conversation/item/type/author/reader/content, verifies pinned keys and recipient membership, persists content/receipts before emitting evidence, rolls back failed writes, bounds stored receipts and replays after reconnect. Foreground/focus guards exclude push previews and background routes. Message IDs and retained-file completion drive read effects; rolling history and blob persistence races have regressions.

Native incoming UI requires a live authenticated callId, nonce/UUID/expiry-validated private intents and explicit answer. Self-managed registration replaces only LastCall's old account. Call setup is mic-free, runtime ownership is bounded, native expiry closes the matching connection and stale actions cannot affect another call. A weak module dispatcher avoids extra broadcast dependency/context retention. The own call activity reveals only caller/control data on lockscreen.

Video retains fresh sender parameters in the SDP queue and guards stale RTCP samples/call identity. Native congestion control owns actual rate; the new ceiling/healthy recovery avoids a permanent low-quality trap. Missing estimates and raw base RTT alone do not prove congestion. Perceived quality still needs phones.

The local monitor binds loopback, exposes an allowlisted read-only status projection and no raw traces/commands/credentials. Main requested and verified removal of activity-stage-derived prior-gate passes; a red/green regression now requires real log evidence.
