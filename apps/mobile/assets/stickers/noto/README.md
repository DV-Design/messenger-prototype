# Noto animated emoji

Lottie animations of the Noto emoji by Google, downloaded from fonts.gstatic.com
(https://googlefonts.github.io/noto-emoji-files/). The artwork is licensed under
CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/); attribution is shown in
Settings -> About. File names are the emoji code points.
