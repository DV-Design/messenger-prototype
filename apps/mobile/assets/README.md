# LastCall app icon

`lastcall-icon.png` is the project-bound app icon edited from the satellite-dish
logo supplied by the user on 2026-10-28. Built-in imagegen was used; no CLI/API key.
The generated square is consumed by Expo app configuration and native prebuild.

Prompt: preserve the central white satellite-dish pictogram, direction/geometry
and purple circular badge; remove the large white margins and photographic
background; center the purple circle at about 90% of a clean white square, about
5% padding per side; clean flat edges, no text, added objects or diffuse shadow.
Requested raster size was 1024 square; tool output is 1254 square and Expo handles
the platform-specific icon sizes. The source attachment was not overwritten.
